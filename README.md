# AlphaTrace Agent

基于财务异常驱动的上市公司业绩归因与证据验证智能体。

## 当前状态

项目处于准备阶段，尚未实现可运行的分析系统。目标公司、金融数据、计算规则和团队分工待确认。

## 初期目标

围绕一家上市公司的两个完整年度和一种财务异常，逐步实现：

1. 读取人工核对的结构化财务数据。
2. 使用 Python 计算财务变化、识别异常并校验结果。
3. 检索本地年报，保留文件、页码和原文引用。
4. 通过 LLM 工具调用调查异常，并判断证据支持程度。
5. 导出结构化结果和运行日志。

财务计算事实、证据支持的经营解释与未验证假设应分别呈现。

## 拟定技术路线

Python 确定性计算 + 本地证据检索 + LLM 工具调用；展示界面待核心流程验证后确定。

## 下一步

- 确认报名状态、初赛提交清单及截止时刻。
- 确定目标公司、年份和数据来源。
- 与金融成员确认计算口径及人工参考结果。
- 制定输入 Schema，优先实现财务计算模块。

## 数据与配置

API 密钥放在本地环境变量中，不提交到版本库。原始财报、运行日志和生成结果默认不纳入版本控制；后续单独整理可复现的演示数据。
