## 在演示机器上启动

1. 获取当前源码；先检查 `git status`，不要覆盖同学的未提交工作。
2. 准备 Node.js 22、pnpm 10.34.3（项目 `.mise.toml` 指定）。首次安装需要依赖下载条件，录屏前完成。
3. 确认白名单 JSON 位于 `frontend/public/data/gree-display.json`。本机现有包 SHA256：`082f017e6b10789bb9eae133bf784d5f6433b4b7555aa6ea6d6ecdd1d4e919ca`。该值仅用于交接对照，不是来源数字签名。
4. 从 `frontend/` 启动开发服务；如果 8443 已有当前项目服务，直接使用。

```powershell
cd D:\Projects\TraceLab\frontend
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://localhost:8443/>。不需要启动 Python 服务，不需要 API Key。不把服务绑定或发布到公网作为本次交付的隐含步骤。

另一终端可执行：

```powershell
cd D:\Projects\TraceLab\frontend
pnpm typecheck
pnpm test
pnpm build
```

如果真实资料不可用，检查展示包是否缺失、JSON是否经过导出器生成、当前前端与包版本是否对应。不要选择任意 PDF 替代，也不要改校验规则或用模拟数据补齐真实案例。目录中的手工 JSON 不会获得额外来源认证。

## 需要重新导出时（已有授权资料的本机）

演示已备好 JSON 时无需执行这一节。当前关联路径为：

| 角色 | 本地运行目录 | 前端用途 |
|---|---|---|
| 财务及来源修订快照 | `outputs/final_revision/20261017T093152-d80de1cefa` | 金额、利润桥接、现金流勾稽、核验/冲突 |
| 真实 Agent 历史 | `outputs/agent_live/20261017T151343-d0d3b954f5` | search/get/error 审计摘要 |
| PDF 提取结果 | `outputs/pdf_extract/20261017T195532-0c947edc10` | 两期提取值与可信值比较 |
| 构造陈述核查 | `outputs/report_check/92ddd5a529414b028c8613414f40ac0c` | 方向错误及证据 |

上述目录本次检查均存在，未重新读取或核验私有原始附件。重新导出还需要原运行引用的本地 PDF/输入及一致的哈希关联；只有目录名存在并不足以保证新机器可复现。文件格式与校验机制见[结果集成文档](frontend-results-integration.md)。

用已安装 requirements 的 Python，从仓库根目录执行。输出用新目录，导出失败时不会替换浏览器展示包：

```powershell
$displayStamp = Get-Date -Format 'yyyyMMddTHHmmssfff'
$displayFile = "outputs/frontend_display/$displayStamp/gree-display.json"
python -X utf8 -m tracelab.display_export `
  --stage2-run outputs/final_revision/20261017T093152-d80de1cefa `
  --agent-run outputs/agent_live/20261017T151343-d0d3b954f5 `
  --report-check-run outputs/report_check/92ddd5a529414b028c8613414f40ac0c `
  --pdf-extract-run outputs/pdf_extract/20261017T195532-0c947edc10 `
  --financial-details `
  --output $displayFile
if ($LASTEXITCODE -eq 0) {
  New-Item -ItemType Directory -Force frontend/public/data | Out-Null
  Copy-Item -LiteralPath $displayFile -Destination frontend/public/data/gree-display.json
} else {
  throw '展示导出失败，未替换前端案例。'
}
```

此命令只导出既有成果，不运行新的 Qwen 调查。原始快照和历史运行不覆盖。完整 modules 参数须保留，否则 PDF/纠错等辅助区会缺少结果。
