## 费用计算与30元预算
公式：每轮C=(输入Token×该输入档单价+输出Token×该档输出单价)/1000000。缓存按未命中计算，属于保守公开价核算，不是账单实际扣款。

1. 不依赖字节估计的极保守模型容量界：997952输入、1200输出，单轮4.8477696元；五轮24.238848元。此仅为已公布标准推理价、官方容量限制被遵守的条件上界，不包含未知合同/税务因素；且不符合60000总Token限制，程序不会按此发请求。
2. 若能够可靠保证整次60000总Token且输出最多6000，所有单轮均落首档。最大值=(54000×0.8+6000×2)/1000000=0.0552元。单轮在整个60000预算内的最大值=(58800×0.8+1200×2)/1000000=0.04944元；五轮必须共享60000，不能将单轮上界重复五次再称为受约束总额。
3. 原代码16000字节+256不是经过证明的Token上界；按该估计可算单轮0.0154048元、五轮0.077024元，但这不是可用于真实发送的保证值。
4. 建议保留30.00元整次调查上限，不增加任何技术上限；在可靠计量和账号规则确认后，按条件计算可预留0.06元标准推理费用（不是已承诺含税总价）。目前正式状态为blocked，不建议执行。
