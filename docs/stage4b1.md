# 第四阶段 B-1：财务事实与证据接口

日期：2026-10-17。本阶段仅本地离线开发；无真实 API 请求、无真实密钥读取、无提交推送。开始时 main 工作区干净。原有会计公式、Decimal 计算、原始附件和历史运行均未修改。

## 来源边界

删除 stage3 与 analysis_contract 中用于披露解释准入的 E07 前缀判断，改用 source_contract 的本地来源记录。仍保留 E07 的历史摘录定位映射；映射用于找到原文，不是验证豁免。

加载器只接受 inventory 内 2024/2025 原始年报文件，校验文件哈希、PDF 页、印刷页、逐字摘录及来源类型，再绑定证据内容、关联项目和比较口径。模型不能通过输出 verified 标记授予自己来源权限，Schema 仍拒绝额外字段。金融组内部 Word 和 Excel 不能作为原始年报引用。

披露解释的所有引用必须来自本次输入且具有匹配的本地核验记录；引文必须逐字存在，每个项目需要相关证据，每段引用也必须关联本条项目。current_period 与 yoy 分开；明确包含两期的 both_periods 原表可支持对应期间的描述，但不因此证明因果。缺少明确口径的解释拒绝通过。

这些哈希是可信本地加载后的完整性检查，不是数字签名或互联网真实性认证。不能接受模型或任意外部 JSON 自带的来源记录作为信任根；恢复保存的 payload 应重新经过原始快照加载。原文摘要、因果强度和跨口径自然语言推断仍需人工审核。

旧历史 payload 没有来源记录时，重新验证披露解释会失败；应从其原始快照重新加载，而非给历史模型结果回填“已核实”。旧失败样本文件保持不变，仅在隔离测试中模拟加载器来源记录，继续验证原先的金额、百分比和引文规则。

## 只读事实工具

沿用原 list/search/get 证据工具和 Decider 接口，新增：

| 行动 | 参数 | 返回 |
|---|---|---|
| facts_list | 空对象 | 本轮准入项目名称、身份、层级、来源状态 |
| fact_get | fact_id | 原有金额字符串与单位、期间、缺失字段状态、层级、关联证据和来源运行编号 |

工具不计算、不写文件、不接受路径或修改参数。未知或未通过当前加载器核验的项目被拒绝。查询与证据结果均返回副本，决策器只得到状态副本。共用最大轮数、工具次数、输入和输出大小限制：默认 6 轮、4 次工具调用，单个输入/结果 100000 字节、决策 30000 字节、累计状态 500000 字节。

当前最终版快照准入 **44 个事实**：29 个核心指标、本期票据保证金调节额、14 个现金流直接法分项。现金流净额沿用 operating_cashflow，避免 cash_16 重复身份。金额保持元和既有亿元展示字符串；本期保证金只有 current，base/change 明确 unavailable_not_zero。工具不提供未核验同比贡献率。

扩充事实重新对照已保存的 PDF 金额记录及差额；新增现金流分项的 ID、原文与金额核对通过后才绑定来源。层级标签用于定位，不代表新增会计关系获准；accounting_links 仍只能使用原来已核验的关系。

## 冲突隔离

- cash_26、cash_27 不进入事实集合。
- fair_value_income 暂不开放查询，避免把有争议的展示值升级为事实。E11 原始年报片段可检索且来源已核验，但没有准入的对应事实，不能单凭它通过该项目的披露解释。
- fee_income 因本期为空不可完整计算，不开放该项目查询；不是把空白当零。
- 五处旧定位继续保留为附件修订问题。新增证据只绑定实际核对过的原始年报页码，不认证旧错误定位。
